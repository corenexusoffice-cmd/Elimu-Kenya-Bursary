# Elimu Kenya — updated application prototype

Open index.html; no installation or build required.

Photo 1 has been removed from assets, slideshow and gallery. Dashboard funding amounts are read-only. The applicant enters their band without selecting a monetary amount; the system assigns Band 1: KSh 20,000, Band 2: KSh 16,250, Band 3: KSh 12,500, Band 4: KSh 8,750, Band 5: KSh 5,000. These remain illustrative project amounts, not official HELB entitlements.

Three-step form: searchable, scrollable public institution list; course and year; HELB/HEF support alongside supplied logo; funding band; full name; birth year; email; phone; all 47 counties; sub-county; town/village; location; sub-location; parent/guardian and relationship; circumstances. No national ID requested. Review and printable receipt show the system-assigned amount and Under review demo status.

Institution coverage includes public chartered universities, specialized public institutions and constituent colleges. Verify the current CUE register before launch: https://www.cue.or.ke/index.php?option=com_phocadownload&view=category&id=81

Optional drafts are saved only on this browser. Clear saved draft removes personal entries. No backend or real submission, assessment, funding, email or payment service exists. Use fictional details. Live operation needs secure server-side validation, authoritative band verification, storage and actual notification services.

Design refinement: removed collection gallery, numbered captions, filters, enlargement dialog and top demo banner. Photography now forms integrated education scenes with original inspirational overlay copy. Three Apply bursary links appear in the hero, funding section and graduation quote. HELB question has explicit high-contrast styling. Prototype identification remains in the application and receipt; no real submission or notification service has been added.
